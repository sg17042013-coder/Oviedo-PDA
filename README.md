# OVIEDO PDA 1.0

PDA policial ficticia para el servidor de Roblox ER:LC OVIEDO RP.

## Publicar en GitHub Pages
1. Crea un repositorio llamado `OVIEDO-PDA`.
2. Sube `index.html` a la raíz del repositorio.
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige `main` y `/ (root)` y guarda.
6. Abre la URL que GitHub Pages te indique.

## Funciones
- Panel con contadores y actividad reciente.
- Registro y búsqueda de ciudadanos.
- Registro de vehículos y matrículas RP.
- Incidencias con estados Abierta / En curso / Cerrada.
- Emisión e historial de multas.
- Consulta rápida global.
- Indicativo del agente.
- Exportar e importar copia JSON.
- Diseño adaptable a móvil.

## Importante
Los datos se guardan en el navegador del dispositivo mediante localStorage. No hay inicio de sesión real, base de datos compartida ni sincronización entre agentes. Está pensada para roleplay y usa datos ficticios; no es una herramienta policial oficial.
